## Objective

Integrate the T14 correctness checks and full load matrix with structured progress, protocol metadata, normalized throughput/latency/contention metrics, and isolated resets.

## Acceptance Criteria Served

US-9, US-17, US-19, US-36, US-37, US-38, US-44, US-65.

## Affected Files / Areas

- `bench/exp/strategies/` (`correctness.ts`, `strategies.ts`, `load.ts`, `db.ts`, `run-matrix.sh`, `summarize.py`).
- Scenario registry and structured adapters for shapes, clients, strategies, sync mode, and repetitions.
- Integration tests with a reduced deterministic matrix.

## Test-First Plan

- Failing tests first: two-second warm-up / ten-second window / three-repetition definition; median and range aggregation; complete metric mapping (TPS, debit/credit TPS, p50/p95/p99, retries, serialization failures, version conflicts, deadlocks, exhausted operations, failed payments, lock acquisition, lock waiters, rollbacks, sample counts); rotated Latin-square order; per-cell reset; correctness-gate failure gives `INCOMPLETE`; reduced-matrix progress events.

## Implementation Notes

- Preserve the accepted full protocol; automation uses reduced durations and cells without weakening the production definition.
- Map every current JSONL field; unknown fields are not silently dropped.
