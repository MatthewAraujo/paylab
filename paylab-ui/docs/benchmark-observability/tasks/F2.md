# F2 — Typed benchmark client, failure taxonomy, and test support

## Objective

Provide the browser-side data layer for the benchmark surface: a credential-free typed client on the configured API base URL, an explicit failure taxonomy, TanStack Query hooks for every read and for the Baseline write, and the typed fixtures and request-routing fetch stub that every later test uses.

## Acceptance Criteria Served

US-4, US-5, US-32 (taxonomy behind the states), US-96.

## Affected Files / Areas

- New benchmark feature module under `src/features/benchmarks/` for the client, results, query keys, and hooks (Runs list with cursor, Run detail, progress, default comparison, chosen comparison, trend, Baseline read and select, Artifact metadata and content).
- `src/test/` for a typed fixture builder derived from the generated schema and a fetch stub that routes by URL and records requests.
- `src/lib/env.ts` reused for the base URL.

## Test-First Plan

- Failing tests first, at the network boundary: a 404 without an error `code` is "capability unavailable"; a 404 with `BENCHMARK_RUN_NOT_FOUND` or `BENCHMARK_ARTIFACT_NOT_FOUND` is "not found"; `BENCHMARK_ARTIFACT_UNAVAILABLE` is "file not available on this machine"; a 422 with `BENCHMARK_BASELINE_INELIGIBLE` or `BENCHMARK_RUN_NOT_COMPARABLE` is a refusal with its reason; a thrown fetch is "unreachable"; a body that is not JSON or does not have the expected shape is "malformed"; requests carry no `Authorization` header and use the configured base URL; cursors, limits, offsets, and repeated `dimension` parameters are sent exactly as given.
- Hook tests through a real `QueryClientProvider`: data, loading, error, retry, and that a refresh failure keeps the previous data available.

## Implementation Notes

- Use `openapi-fetch` with the generated types, without the server-only key and never through `createServerApiClient`.
- Keep the taxonomy in one place: components receive discriminated results, never raw responses.
- Fixtures are typed by the generated schema so contract drift breaks tests at compile time.
- Polling intervals and stop conditions are parameters here and used by F6.

## Dependencies

F1.

## Completion Signal

Every benchmark route has a typed, tested function and hook returning the taxonomy; the fixtures and stub exist; no component needs to call `fetch` itself.
