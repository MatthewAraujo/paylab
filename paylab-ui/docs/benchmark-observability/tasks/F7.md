# F7 — Run detail

## Objective

Implement the complete Run detail for native, Imported, and Incomplete Runs: provenance, environment, dataset, suite and protocols, every scenario and normalized metric, the failure evidence and diagnostic measurements, the Artifact inventory, and shortcuts to comparison.

## Acceptance Criteria Served

US-35..51.

## Affected Files / Areas

- Run detail route and feature components; scenario and metric tables reused later by the comparison.

## Test-First Plan

Rendered-route tests with typed fixtures:

- Native completed Run: identity, timing, environment and dataset provenance, executor and schema version, protocols per scenario, scenarios grouped by `group`, metrics with label, unit, direction, aggregation, and dimensions; a full concurrency Run renders groups collapsed and expands on demand; an unknown future metric renders generically.
- Missing values show "not recorded"; strategy-dimension metrics are labelled by their dimension.
- Incomplete Run: order is failure evidence (scenario, command, exit status or interruption, times, summary), then a visibly separate "Diagnostic measurements completed before failure" section stating it cannot be compared or become the Baseline, then Artifacts; no overall classification and no Baseline action.
- Imported Runs: separate T13 baseline, T13 adopted, and T14 records with their own provenance and evidence, an explanation that they predate the executor, and unknown commit and branch shown as such.
- Artifact inventory with kind, label, scenario, size, and availability, and "not available on this machine" for a missing file.
- Shortcuts to compare with the previous compatible Run and with the Baseline; unknown Run gives a not-found state; states for loading, error with retry, and unavailable.

## Implementation Notes

- The Baseline action itself is F10; leave a clearly disabled slot rather than a placeholder that behaves.
- Payload size: a full T14 record is about 555 KB; render lazily and never lay out all metric rows at once.
- Native Runs never tolerate missing required provenance: a malformed record is a malformed-record state, not "Not recorded".

## Dependencies

F2, F3, F4.

## Completion Signal

Every persisted Run state and all its normalized evidence can be inspected in the console without reading files or the terminal; tests pass.
