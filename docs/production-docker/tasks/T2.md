# T2 — Console production image

## Objective
Build a multi-stage production image for `paylab-ui` that serves the Next.js standalone output as a non-root user, without changing existing build, start, dev or test behavior.

## Acceptance Criteria Served
AC-8 and AC-9 (console part), AC-1 (existing UI commands unchanged) in ../PRD.md.

## Affected Files / Areas
`paylab-ui` Next.js configuration (standalone output behind a build-time switch); new production Dockerfile beside the unchanged development Dockerfile; existing `.dockerignore`.

## Test-First Plan
- AC-1 → without the switch, `next build` output and `pnpm start` are unchanged; UI test, typecheck and lint pass → existing commands in the development image → catches standalone leaking into the default build.
- AC-8 → final image contains `server.js`, `.next/static` and no `src`, `node_modules/.bin` dev tools or `pnpm` → `docker run` → catches copying the workspace.
- AC-8 → the container serves the home route (redirect status) on 0.0.0.0:3000 → container/HTTP → catches wrong hostname binding or missing static assets.
- AC-9 → `id -u` is non-zero → `docker run` → catches root runtime.

## Implementation Notes
Pin pnpm 10.28.1 with `--frozen-lockfile`. The browser API address stays the code default `http://localhost:3333`, so no build argument is needed; never pass secrets as build arguments. The key is read at container start from the credential volume (wired in T3). Keep the development Dockerfile untouched.

## Dependencies
None.

## Completion Signal
Image builds; checks above pass; UI tests, typecheck and lint results recorded.
