## Objective

Turn benchmark preparation, deterministic reset, validation, the invariant gate, and the T13 read/query-plan experiments into registered scenarios executed by the B2 shell.

## Affected Files / Areas

- `bench/run.ts` database-name guard and `bench/lib/seed.ts`, `bench/lib/stats.ts` (reuse, do not duplicate).
- T13 helpers in `bench/exp/` (`suite.py`, `q.py`, `reset.sh`, `clone.sh`) and plan capture into `docs/experiments/plans/` conventions.
- New scenario registry and T13 metric adapters.
- Small-dataset integration tests.

## Test-First Plan

- Failing tests first: forbidden database name refusal; each preflight failure (missing env, Docker, PostgreSQL, migrations, template, dataset, invariant) yields a clear failure; deterministic reset gives identical dataset fingerprints twice; isolation between two mutating groups; invariant violation makes the Run `INCOMPLETE`.
- Protocol metadata test: one warm-up plus seven measured executions, median aggregation.
- Query metric normalization test with a controlled query runner; plan registered as an Artifact.
- All on the small deterministic dataset, never the million-payment one.

## Implementation Notes

- Reuse the existing dataset generator and invariant helper.
- Replace experiment-only output parsing only where a structured adapter is needed; keep raw plans as Artifacts.
- The full destructive setup never runs in the fast unit gate.
