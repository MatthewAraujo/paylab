# F5 — Overview of the latest Benchmark Run

## Objective

Implement the Benchmarks overview for a settled latest Run: identity and provenance, declared headline measurements with scenario context, comparison with the previous compatible Run and the Baseline, notable changes, scenario groups, recent history, and entries to comparison, detail, and trends.

## Acceptance Criteria Served

US-9..24, US-32..34.

## Affected Files / Areas

- Overview route and feature components under `src/features/benchmarks/`.
- Data: Runs list (first page and load-more), the default comparison, the Baseline, and the detail records of the latest Run and its reference (for notable changes and group summaries).

## Test-First Plan

Rendered-route tests with the typed fixtures and request stub:

- Completed native Run: status, exact time, abbreviated commit with reveal and copy, branch, note, provenance, Baseline identity; headline cards only from declared roles, each naming its scenario; the scenario selector changes the featured scenario; no declared role gives the calm "no headline measurement declared" state; error rate shows "not declared".
- Difference from the previous compatible Run and the compact Baseline indication; notable improvements and regressions beyond the 5% band listed and capped with a link to the comparison.
- Scenario groups with counts; recent history with headline values and load-more through the cursor.
- Incomplete latest Run: failure summary and a link to its detail, no headline classification. Imported latest Run: provenance and absent values as "not recorded".
- States: capability unavailable, unreachable with retry, loading, empty history, refresh failure with the previous data kept, and a notice for isolated unreadable records.
- Entries to comparison, detail, and trends carry the right identifiers in their links.

## Implementation Notes

- The latest Run is the newest record whatever its status; the running case is completed by F6.
- Fetch full detail only for what the page computes from (latest and reference); the Baseline indication uses the light list item.
- No composite score, no execution control, no invented metric.

## Dependencies

F2, F3, F4.

## Completion Signal

The overview renders every settled state from real typed data with honest loading, empty, error, and unavailable treatments; tests pass at the route seam.
