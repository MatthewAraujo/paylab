# F9 — Benchmark Comparison

## Objective

Implement the Comparison route: choose two completed Runs (previous compatible by default, the Baseline, or another Run), read compatibility from the API, and present per-scenario states and per-metric raw values, deltas, and direction-aware classifications with distinct summary counts.

## Acceptance Criteria Served

US-59..75.

## Affected Files / Areas

- Comparison route and feature components; selectors backed by the query string; reuse of F7 scenario and metric presentation.

## Test-First Plan

Rendered-route tests:

- With no selection the page uses the default comparison; choosing the Baseline or another Run updates the address and the data; the address alone reproduces a comparison; swap exchanges the two.
- Only completed Runs are offered, and an incomplete or running one is listed as unavailable with the reason (the API's 422 for a forced link is handled too).
- Environment and dataset compatibility is stated first; every scenario shows one of comparable, new, removed, changed definition, environment-incompatible, or dataset-incompatible; a scenario that is not comparable shows no numeric delta and says why.
- Comparable metrics show current, reference, absolute delta, percentage, and classification as text with a non-color cue; the exact ±5% boundary is Stable with raw values visible; informational metrics show values without classification; zero-reference cases follow the rules; a metric on one side only is "not recorded".
- Summary tiles count Improved, Stable, Regressed, Incompatible, and Not recorded separately, with the one-line 5% explanation.
- Large comparisons keep groups collapsed and expand on demand; wide tables scroll inside a labelled, keyboard-focusable region with identity kept visible; unknown Run, loading, error, and unavailable states.

## Implementation Notes

- Compatibility comes from the API; numbers and classification are computed in the console from the two Run records with the F3 rules.
- Comparing an imported Run with a native one legitimately yields "changed" and possibly "environment-incompatible"; present that as evidence, not an error.

## Dependencies

F2, F3, F4, F7.

## Completion Signal

Any two eligible Runs can be compared safely, every incompatibility is explained, and no misleading number is ever shown; tests pass.
