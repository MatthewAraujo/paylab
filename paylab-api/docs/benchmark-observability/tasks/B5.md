# B5 — Import existing T13 and T14 evidence

## Objective

A one-time, deterministic, idempotent importer that reconstructs separate Imported Benchmark Runs for T13 and T14 from existing raw evidence.

## Acceptance Criteria Served

US-31, US-32, US-33, US-34, US-44, US-65.

## Affected Files / Areas

- Import command and mapping module; `package.json` script.
- Read-only sources: `docs/experiments/raw/`, `docs/experiments/plans/`, `T13-results.md`, `T14-results.md`.
- Generated imported Summaries in the versioned Summary directory.
- Fixture tests using trimmed copies of real source data.

## Test-First Plan

- Failing tests first: representative T13 and T14 values pinned; separate Run identities; imported provenance label; absent values stay absent; protocol and environment metadata preserved; second import produces no changes; malformed source fails without partial output.

## Implementation Notes

- Prefer structured sources (JSONL, plans) over scraping prose.
- Reference existing plan files rather than duplicating large content.
- Imported Runs are terminal; no combined historical execution.

## Dependencies

B1.

## Completion Signal

T13 and T14 appear as separate validated imported Summaries with traceable sources; the importer is idempotent.
